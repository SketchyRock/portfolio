# Portfolio

Flask site rendered to static HTML and deployed to GitHub Pages at https://portfolio.idalia.dev (home, about, competitions, projects, photos). Copy lives in `data/*.json`. Public repos and writeups come from GitHub via `sync.py` into `data/cache/`; the Projects page lists only public repos (name, link, GitHub About text), with no hand-kept entries; write-ups are picked by the `type` in their front matter (filters in `data/github.json`). Build with `python build.py` (`--offline` skips the GitHub fetch; `GITHUB_TOKEN` is optional and only avoids the rate limit), test with `pytest` after `pip install -r requirements-dev.txt`. `SITE_BASE` (repo variable, `/` in production) sets the URL prefix. `.github/workflows/pages.yml` builds and deploys on push to `main`, daily, and on demand. Photos: originals in `photos/<album>/` (git-ignored), then `python photos.py`. The apex `idalia.dev` is a different site with mail records; only touch the `portfolio` subdomain.

Each write-up is a competition: they render at `/competitions/<slug>` and the Competitions page lists every `retrospective` by title and date only, newest first. Project write-ups render but are not listed. Nothing on either list is kept by hand; the daily deploy refreshes both. There is no separate writeups page and no theme toggle (the site follows the system color scheme).
